## 1. PRINSIP TERAS SISTEM

### 1.1 Pengguna & Peranan
| Pengguna | Peranan |
|---|---|
| Parent | Pegang device, guided oleh sistem, jadi coach |
| Anak Tahun 3–5 | Fokus utama — soalan subjektif, KBAT |
| Anak Tahun 1–2 | Secondary — soalan objektif, asas |

### 1.2 3 Layer Framework (Universal — semua subjek)
```
LAYER 1 — FAHAM SOALAN
Anak kena faham APA yang soalan kehendaki
sebelum tahu cara jawab.

LAYER 2 — JALAN KERJA
Anak kena tahu CARA atau STRUKTUR
untuk selesaikan soalan.

LAYER 3 — JAWAB & TULIS
Baru anak execute dan tulis jawapan penuh.
```

### 1.3 Backtrack Rule
- Sistem DETECT anak stuck pada layer mana
- Sistem NOTIFY parent: "Anak nampak lemah pada [Topik]. Nak cover dulu?"
- Parent DECIDE — backtrack atau teruskan
- Jika skip — topik prerequisite di-flag dalam progress report

### 1.4 Session Design
- Masa optimum: 15–20 minit
- Soalan per session: 5–8 soalan
- Parent pegang device
- Sistem guide parent apa nak cakap (parent script)

## 2. MATEMATIK

### 2.1 Prerequisite Chain — Pecahan (Topik Kritikal)

```
[T2] Kenali Pecahan Asas (½, ¼, ¾)
  → Faham pecahan sebagai bahagian daripada keseluruhan
        ↓
[T3] Pecahan Setara & Tambah/Tolak Pecahan Wajar
  → Penyebut sama, pecahan setara, KPK asas
        ↓
[T4] Pecahan Tak Wajar & Nombor Bercampur
  → Tukar bentuk, operasi bergabung tambah/tolak
        ↓
[T4] Perpuluhan & Peratus
  → Tukar pecahan ↔ perpuluhan ↔ peratus
        ↓
[T5] Darab & Bahagi Pecahan
  → Darab pengangka × pengangka, bahagi = songsang & darab
```

#### Stuck Detection — Pecahan
| Jika anak stuck pada... | Semak prerequisite... |
|---|---|
| Pecahan setara (T3) | Kenali pecahan asas (T2) |
| Tambah pecahan beza penyebut (T3) | Pecahan setara (T3) |
| Pecahan tak wajar (T4) | Tambah/tolak pecahan (T3) |
| Darab pecahan (T5) | Pecahan tak wajar & nombor bercampur (T4) |

---

#### FORMAT SOALAN — Pecahan T3 (Contoh MVP)

**Layer 1 — Faham Soalan**
```
Soalan asal:
"Ain ada ¾ meter reben. Dia guna ⅜ meter untuk hiasan.
Berapa meter reben yang tinggal?"

Sistem pecahkan kepada:
→ "Soalan ni cakap tentang apa?" [Reben]
→ "Ain ada berapa?" [¾ meter]
→ "Dia guna berapa?" [⅜ meter]
→ "Soalan tanya apa?" [Berapa yang tinggal]
→ "Kalau nak tahu yang tinggal, kita kena...?" [Tolak]

Parent Script L1:
"Jom kita baca soalan sama-sama.
Cuba [Nama] cerita balik — soalan ni pasal apa?"
```

**Layer 2 — Jalan Kerja**
```
Sistem tunjuk langkah tanpa bagi jawapan:
→ Langkah 1: Tengok penyebut dua pecahan ni — sama ke?
→ Langkah 2: Kalau tak sama, kena cari penyebut yang sama dulu (KPK)
→ Langkah 3: Tukar kedua-dua pecahan kepada penyebut baru
→ Langkah 4: Baru boleh tolak pengangka

Parent Script L2:
"Cuba tengok dua nombor bawah ni (penyebut).
Sama ke? Apa kita kena buat dulu kalau tak sama?"
```

**Layer 3 — Jawab & Tulis**
```
Sistem tunjuk format jawapan yang betul:
¾ - ⅜
= 6/8 - 3/8    ← tukar kepada penyebut sama
= 3/8 meter    ← tolak pengangka

Parent Script L3:
"Ok, cuba [Nama] tulis jalan kerja macam yang kita
bincang tadi. Tak apa kalau salah — kita tengok sama-sama."
```

### 2.2 Prerequisite Chain — Nombor Bulat & Operasi

```
[T1] Nombor 0–100, Tambah/Tolak asas, Darab (2,5,10)
        ↓
[T2] Nombor 0–1,000, Semua jadual darab, Bahagi asas
        ↓
[T3] Nombor 0–10,000, Operasi bergabung
        ↓
[T4] Nombor 0–100,000, Operasi kompleks, Penyelesaian masalah
        ↓
[T5] Nombor hingga juta, KBAT — penaakulan & analisis
```

#### FORMAT SOALAN — Operasi Bergabung T3/T4

**Layer 1 — Faham Soalan**
```
Soalan: "Kedai Ali ada 3,450 biji epal.
Dia jual 1,280 biji pada hari Isnin dan
750 biji pada hari Selasa. Berapa baki?"

Sistem pecahkan:
→ "Ada berapa epal mula-mula?" [3,450]
→ "Berapa kali dia jual?" [2 kali]
→ "Soalan tanya apa?" [Berapa baki]
→ "Kita kena tolak berapa kali?" [2 kali, atau jumlahkan dulu]

Parent Script L1:
"Jom highlight maklumat penting dalam soalan ni.
Angka mana yang kita ada? Angka mana yang kita nak cari?"
```

**Layer 2 — Jalan Kerja**
```
Sistem tunjuk dua strategi:
Cara 1: Tolak dua kali
  3,450 - 1,280 = 2,170
  2,170 - 750 = 1,420

Cara 2: Jumlah dulu, baru tolak sekali
  1,280 + 750 = 2,030
  3,450 - 2,030 = 1,420

Parent Script L2:
"Ada dua cara nak selesaikan. Cuba [Nama] pilih cara
yang dia lebih selesa. Kita cuba sama-sama."
```

### 2.3 Prerequisite Chain — Luas & Perimeter

```
[T3] Perimeter bentuk asas (segi empat sama, segi tiga)
  → Jumlah semua sisi
        ↓
[T4] Luas bentuk asas (segi empat tepat, segi empat sama)
  → panjang × lebar
        ↓
[T4] Luas & Perimeter bentuk komposit
  → Pecahkan kepada bentuk kecil, kira, gabungkan
        ↓
[T5] Isipadu cecair
  → Hubungkait dengan konsep ruang 3D
```

#### FORMAT SOALAN — Luas Komposit T4

**Layer 1 — Faham Soalan**
```
Soalan: [Gambar rajah bentuk L]
"Hitung luas rajah di atas."

Sistem pecahkan:
→ "Bentuk ni namanya apa?" [Bentuk L / komposit]
→ "Boleh tak kita kira luas terus?" [Tidak, bentuk tak sekata]
→ "Kita kena buat apa dulu?" [Pecahkan kepada dua segi empat]

Parent Script L1:
"Cuba [Nama] tengok bentuk ni. Ada berapa segi empat
yang kita nampak kalau kita belah dua?"
```

**Layer 2 — Jalan Kerja**
```
Langkah 1: Label bahagian A dan bahagian B
Langkah 2: Cari ukuran yang tertinggal (kira dari ukuran yang ada)
Langkah 3: Kira luas A = p × l
Langkah 4: Kira luas B = p × l
Langkah 5: Jumlahkan A + B

Parent Script L2:
"Kalau kita belah jadi dua bahagian — mana satu
[Nama] nak kira dulu?"
```

## 3. BAHASA MELAYU

### 3.1 Prerequisite Chain — Karangan (Topik Kritikal)

```
[T1-2] Bina ayat mudah yang betul
  → Subjek + predikat, ejaan betul
        ↓
[T3] Karangan Berdasarkan Gambar
  → Faham struktur pendahuluan–isi–penutup
  → Bina ayat daripada pemerhatian gambar
        ↓
[T4] Karangan Fakta / Penerangan
  → Hujah menggunakan fakta
  → Ayat majmuk, peribahasa mudah
        ↓
[T5] Karangan Imaginasi / Kreatif
  → Cipta plot, watak, dialog
  → Bahasa indah, simpulan bahasa
```

#### Stuck Detection — Karangan
| Jika anak stuck pada... | Semak prerequisite... |
|---|---|
| Tak tahu nak mulakan karangan (T3) | Bina ayat mudah (T1-2) |
| Pendahuluan lemah (T3-5) | Faham struktur karangan (T3) |
| Isi kosong / tak relevan (T4) | Karangan gambar — susun idea (T3) |
| Bahasa lemah (T5) | Perbendaharaan kata & peribahasa (T4) |

---

#### FORMAT SOALAN — Karangan Gambar T3

**Layer 1 — Faham Tajuk / Gambar**
```
Tugasan: "Tulis karangan berdasarkan gambar di bawah.
[Gambar: Majlis hari jadi]"

Sistem bantu anak "download" idea:
→ "Gambar ni tunjukkan apa?" [Majlis hari jadi]
→ "Siapa yang ada dalam gambar?" [Keluarga, kawan]
→ "Di mana majlis ni?" [Di rumah]
→ "Bila agaknya?" [Petang / hujung minggu]
→ "Apa yang sedang berlaku?" [Tiup lilin, potong kek]

Parent Script L1:
"Jom kita tengok gambar ni sama-sama.
Cuba [Nama] cerita — apa yang dia nampak?"
```

**Layer 2 — Bina Struktur (Rangka)**
```
Sistem bagi rangka kosong untuk anak isi:

PENDAHULUAN (4–5 ayat):
→ Bila? [________________]
→ Siapa yang terlibat? [________________]
→ Di mana? [________________]
→ Apa tujuan? [________________]

ISI 1 — Persediaan (3–4 ayat):
→ Apa yang dibuat sebelum majlis? [________________]

ISI 2 — Semasa Majlis (4–5 ayat):
→ Apa yang berlaku? [________________]
→ Perasaan semua orang? [________________]

PENUTUP (3–4 ayat):
→ Apa pengajaran / perasaan akhir? [________________]

Parent Script L2:
"Ok, sekarang kita ada rangka. [Nama] tak perlu
fikir semua sekaligus — kita isi satu bahagian
dulu. Pendahuluan dulu — bila majlis ni?"
```

**Layer 3 — Tulis**
```
Anak tulis berdasarkan rangka yang dah diisi.
Sistem ingatkan:
→ Mulakan setiap perenggan dengan ayat topik
→ Guna kata hubung (kemudian, selepas itu, akhirnya)
→ Semak ejaan & tanda baca

Parent Script L3:
"Bagus! Sekarang cuba tulis dalam ayat penuh.
Tak apa kalau tak sempurna — kita boleh baiki lepas tu."
```

---

### 3.2 Prerequisite Chain — Pemahaman

```
[T1-2] Baca teks pendek, jawab soalan literal
  → Jawapan ada terus dalam teks
        ↓
[T3] Pemahaman — soalan explicit & implicit mudah
  → Mula cari maklumat yang "tersembunyi sikit"
        ↓
[T4] Pemahaman — soalan inferens
  → Jawapan TIDAK ada terus dalam teks
  → Kena "baca antara baris"
        ↓
[T5] Pemahaman — analisis & beri pendapat
  → Sokong pendapat dengan bukti dari teks
  → KBAT — soalan terbuka
```

#### FORMAT SOALAN — Pemahaman Inferens T4

**Layer 1 — Faham Soalan**
```
Teks: [Petikan tentang pencemaran alam]
Soalan: "Pada pendapat kamu, mengapakah
penduduk kampung itu berpindah?"

Sistem bantu:
→ "Soalan ni tanya pendapat atau fakta?"
  [Pendapat — tapi kena ada bukti dari teks]
→ "Ada tak ayat dalam teks yang cerita
   kenapa penduduk tak selesa?" [Cari bersama]

Parent Script L1:
"Soalan ni tak ada jawapan terus dalam teks.
Kita kena guna maklumat dalam teks untuk
buat kesimpulan sendiri. Jom cari clue."
```

**Layer 2 — Jalan Kerja**
```
Langkah 1: Cari ayat dalam teks yang berkaitan
Langkah 2: Buat kesimpulan dari ayat tu
Langkah 3: Susun dalam ayat jawapan yang lengkap

Format jawapan yang betul:
"Pada pendapat saya, penduduk kampung itu
berpindah kerana ___[sebab 1]___ dan
___[sebab 2]___. Ini terbukti apabila
penulis menyatakan bahawa ___[petikan teks]___."

Parent Script L2:
"Cuba [Nama] cari dalam teks — ada tak
perkataan atau ayat yang bagi clue?"
```

## 4. SAINS

### 4.1 Prerequisite Chain — Jirim & Perubahan

```
[T1-2] Pemerhatian benda sekeliling
  → Pepejal vs bukan pepejal (pemerhatian deria)
        ↓
[T3] Jirim — Pepejal, Cecair, Gas
  → Sifat setiap keadaan, contoh harian
        ↓
[T4] Perubahan Jirim
  → Sebab & akibat perubahan (haba, sejuk)
  → Proses: lebur, beku, sejat, kondensasi
        ↓
[T5] Kitar air & fenomena alam
  → Hubungkait perubahan jirim dengan alam semula jadi
```

#### FORMAT SOALAN — Jirim T3

**Layer 1 — Faham Soalan**
```
Soalan: "Mengapa air bertukar menjadi wap
apabila dipanaskan? Jelaskan."

Sistem pecahkan:
→ "Air tu dalam keadaan apa?" [Cecair]
→ "Wap tu dalam keadaan apa?" [Gas]
→ "Apa yang berlaku — ia berubah atau tidak?" [Berubah]
→ "Apa yang menyebabkan perubahan tu?" [Haba / dipanaskan]

Parent Script L1:
"Cuba [Nama] fikir — air dalam periuk yang
mendidih tu, apa jadi dengan air tu lama-lama?"
```

**Layer 2 — Jalan Kerja**
```
Struktur jawapan Sains:
1. Nyatakan fakta / proses [Apabila air dipanaskan...]
2. Terangkan sebab saintifik [Haba menyebabkan...]
3. Beri kesimpulan [Oleh itu, air bertukar kepada...]

Parent Script L2:
"Dalam Sains, jawapan kena ada tiga bahagian —
apa yang berlaku, kenapa berlaku, dan kesimpulan.
Cuba [Nama] buat satu-satu."
```

### 4.2 Prerequisite Chain — Ekosistem & Rantai Makanan

```
[T1-2] Haiwan & tumbuhan — ciri asas
        ↓
[T3] Keperluan asas hidupan — makanan, air, udara
        ↓
[T4] Pembiakan haiwan & tumbuhan
        ↓
[T5] Ekosistem — hubungkait pengeluar, pengguna, pengurai
  → Rantai makanan, siratan makanan
  → Kesan gangguan ekosistem (KBAT)
```

#### FORMAT SOALAN — Ekosistem T5

**Layer 1 — Faham Soalan**
```
Soalan: "Jika katak dalam ekosistem sawah
pupus, apakah kesannya kepada ekosistem tersebut?
Bincangkan."

Sistem bantu:
→ "Katak dalam rantai makanan — dia makan apa?" [Serangga]
→ "Apa yang makan katak?" [Ular]
→ "Kalau katak pupus — apa jadi dengan serangga?" [Bertambah banyak]
→ "Apa jadi dengan ular?" [Berkurangan makanan]

Parent Script L1:
"Jom kita lukis rantai makanan sawah dulu
sebelum jawab. Ini akan bantu [Nama] nampak
kesannya dengan lebih jelas."
```

**Layer 2 — Jalan Kerja**
```
Struktur jawapan KBAT Sains:
1. Kesan kepada mangsa katak [Serangga bertambah → ...]
2. Kesan kepada pemangsa katak [Ular berkurangan → ...]
3. Kesan kepada tumbuhan / hasil pertanian [...]
4. Kesimpulan — keseimbangan ekosistem terganggu

Parent Script L2:
"[Nama] dah nampak dalam rantai makanan tadi.
Sekarang kita cerita satu-satu — apa jadi
dengan setiap haiwan kalau katak hilang?"
```

## 5. BAHASA INGGERIS (ENGLISH)

### 5.1 Prerequisite Chain — Writing

```
[T1-2] Simple sentences (S + V + O)
  → Basic vocabulary, correct spelling
        ↓
[T3] Guided writing — picture-based paragraphs
  → Introduction, body, conclusion structure
        ↓
[T4] Factual / descriptive writing
  → Paragraphs with supporting details
  → Connectors: however, therefore, in addition
        ↓
[T5] Creative writing & formal writing
  → Story (plot, characters, dialogue)
  → Report / formal letter (format & tone)
```

#### FORMAT SOALAN — Guided Writing T3

**Layer 1 — Understand the Task**
```
Task: "Write a story based on the picture.
[Picture: Children playing at the park]"

System helps anak:
→ "What do you see in the picture?" [Children, park, swings]
→ "Who are the main characters?" [Friends / siblings]
→ "What are they doing?" [Playing, laughing]
→ "How do they feel?" [Happy, excited]

Parent Script L1:
"Let's look at the picture together.
Can [Name] tell me what is happening?"
```

**Layer 2 — Build the Structure**
```
System provides guided frame:

INTRODUCTION (3–4 sentences):
→ Who? [________________]
→ Where? [________________]
→ When? [________________]

BODY (4–5 sentences):
→ What happened? [________________]
→ How did they feel? [________________]

CONCLUSION (2–3 sentences):
→ How did it end? [________________]
→ What did they learn / feel? [________________]

Parent Script L2:
"Let's fill in the frame first.
What can [Name] write for 'Who'?"
```

---

### 5.2 Prerequisite Chain — Reading Comprehension

```
[T1-2] Read short texts, answer who/what/where
        ↓
[T3] WH questions — answers found directly in text
        ↓
[T4] Inference questions — read between the lines
        ↓
[T5] Evaluate, justify, give opinions with evidence
```

---

### 5.3 Prerequisite Chain — Grammar

```
[T1-2] Nouns, verbs, basic adjectives
        ↓
[T3] Singular/plural, simple present & past tense
        ↓
[T4] Adjectives, adverbs, conjunctions (and, but, because)
        ↓
[T5] Complex sentences, conditionals, passive voice
```

## 6. PARENT SCRIPTS — PRINSIP UMUM

### 6.1 Ayat yang Encourage (Guna Ini)
```
✅ "Jom kita baca soalan sama-sama."
✅ "Cuba [Nama] cerita balik — soalan ni pasal apa?"
✅ "Tak apa kalau salah — kita tengok sama-sama."
✅ "Bagus! [Nama] dah faham bahagian ni."
✅ "Hampir betul! Cuba sekali lagi — tengok bahagian ni."
✅ "Jom kita lukis dulu sebelum kira."
✅ "Pilih cara yang [Nama] rasa paling senang."
```

### 6.2 Ayat yang Elak (Jangan Guna)
```
❌ "Senang je ni! Kenapa tak tahu?"
❌ "Dah ajar berapa kali dah ni."
❌ "Budak lain boleh buat."
❌ "Kalau exam macam ni, habislah."
❌ Diam panjang bila anak salah — terus tengok muka
```

### 6.3 Flow Bila Anak Stuck
```
1. Jangan terus bagi jawapan
2. Tanya soalan pemandu (ikut Layer 1 & 2)
3. Bagi masa 30–60 saat untuk anak fikir
4. Kalau masih stuck — sistem akan suggest backtrack
5. Parent decide — backtrack atau hint tambahan
```

### 10.3 Strategi Generate Soalan — Hybrid

**Arkitektur:**
```
PRE-GENERATED (80% kes biasa)
- Soalan disimpan dalam Supabase (jadual: questions)
- Di-generate sekali, serve berkali-kali
- Laju, kos rendah, boleh QC sebelum publish
- Covers soalan standard per topik per tahun

REAL-TIME via Claude API (20% kes khas)
- Trigger bila bank soalan habis
- Soalan adaptive lepas backtrack detect
- Hint spesifik berdasarkan jawapan anak
- Soalan exam-style bila diminta
- Auto-simpan ke Supabase selepas generate
  → Jadi pre-generated untuk user lain

SELF-IMPROVING LOOP:
Makin ramai guna → makin banyak soalan dalam bank
→ makin laju & murah untuk semua user
```
